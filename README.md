## About

AI engineer focused on **LLM applications and multi-agent systems** — I build agents that reason, debate, and automate real workflows, then wrap them in interfaces people can actually use.

- 🤖 Deep in the agent stack: reasoning strategies (ToT, CoT, Reflexion, Self-Consistency), multi-agent orchestration, browser automation
- 🛠️ Python-first with Gradio/Reflex frontends; TypeScript for the web
- 📊 Care about responsible AI — built bias-detection and fairness-evaluation pipelines, not just demos
- 🌐 Portfolio: **[dhruvlabs.dev](https://dhruvlabs.dev)**
